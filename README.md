# Hippla

Website for Hippla Estate, served at [hippla.in](https://hippla.in).

React + Vite, frontend only. Pushing to `main` deploys to GitHub Pages.

```
npm install
npm run dev
```

- Pages are in `src/pages/` (Home, Contact, Gallery).
- To add a coffee to the Gallery, add an entry to the `coffees` list in `src/pages/Gallery.jsx`.
